# Roth Planner — Deep Audit (2026-06-22)

Adversarial multi-lens audit (math accuracy / 2026 tax-law currency / web-UI organization / security) with double-round verification. Every finding below carries an independent `file:line` re-derivation.

## Methodology
- 11 adversarial finders read `engine/` (36 files), `models/`, `views/` (17 files), `app.py`, `deploy/build_stlite.py` in full, each in a distinct mindset (risk-averse, contrarian, modernist, security).
- Each raised finding was verified in two independent rounds (Round 1: skeptic attempts refutation; Round 2: independent re-derivation from source). The orchestrated fleet was disrupted by transient API rate-limiting, so all surviving and disputed findings were re-verified directly in a low-concurrency second pass; only results carrying exact `file:line` proof are recorded here.

## Verdict
Engine math and 2026 tax constants are sound — no wrong-dollar defect in the core scenario/tax/IRMAA/ACA computation for the documented household (MFJ, ages 61/55, FRA 67, no muni interest). The real issues are three user-visible view-layer bugs plus headroom-vs-engine drift that surfaces only for non-default households. No security exposure.
